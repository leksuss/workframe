# Frontend Quality Checklist

Use this after frontend implementation and before handing work back.

- The first screen is the actual usable experience unless the user explicitly requested a landing page.
- Existing design system, icon library, and styling conventions were followed.
- Layout works on mobile and desktop.
- Text does not overlap or overflow its controls/cards/panels.
- Fixed-format UI elements have stable dimensions.
- Buttons, form controls, menus, tabs, toggles, sliders, and toolbars use familiar patterns.
- Loading, empty, error, hover, active, focus, and disabled states are considered where relevant.
- Color palette is not a one-note wash of a single hue family unless the brand requires it.
- Motion is helpful and restrained.
- Visual verification was performed with a browser or screenshot when possible.
