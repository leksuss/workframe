## MODIFIED Requirements

### Requirement: Доступность без поддержки skills

Workframe MUST делать проверку согласованности выполнимой в AI-клиентах, не поддерживающих skills, и MUST поставлять исполняемый workflow аудита для клиентов, которые skills поддерживают. Workflow MUST задавать порядок исполнения и обработку находок, но MUST NOT дублировать содержание срезов, которое остаётся в чек-листе.

#### Scenario: Клиент читает только общие правила

- **WHEN** агент работает в клиенте без механизма skills
- **THEN** правила и чек-лист в payload содержат достаточное описание срезов и классификации
- **AND** отсутствие skill не блокирует ни сверку, ни аудит

#### Scenario: Клиент поддерживает skills

- **WHEN** агент запускает workflow аудита в поддерживаемом клиенте
- **THEN** workflow задаёт подготовку change и ветки, порядок срезов, обработку находок по классам, обновление реестра и условия остановки
- **AND** содержание каждого среза берётся из чек-листа, а не из текста workflow

#### Scenario: Содержание среза меняется

- **WHEN** проект добавляет, убирает или переформулирует срез аудита
- **THEN** изменение вносится в чек-лист
- **AND** workflow не требует синхронного изменения, потому что не повторяет содержание срезов
