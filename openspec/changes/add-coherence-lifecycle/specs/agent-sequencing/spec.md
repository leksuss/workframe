## MODIFIED Requirements

### Requirement: Бэклог отложенных улучшений

Агент MUST откладывать замеченные улучшения в бэклог, а не чинить их по ходу. Бэклог активного change ведётся в секции `## Фаза 2. Углубление` файла `tasks.md`, а невыполненные пункты MUST переноситься в постоянный реестр расхождений до архивации change.

#### Scenario: Агент замечает недочёт в готовом блоке

- **WHEN** агент при работе над текущим пунктом замечает недочёт в уже сделанном блоке или придумывает улучшение
- **THEN** агент дописывает пункт в секцию `## Фаза 2. Углубление` файла `tasks.md`
- **AND** не чинит недочёт немедленно, а продолжает текущий пункт

#### Scenario: Недочёт является блокером

- **WHEN** замеченный дефект не даёт построить следующий блок каркаса
- **THEN** агент устраняет дефект сразу как часть текущего пункта
- **AND** не считает его отложенным улучшением

#### Scenario: Change архивируется с незакрытым бэклогом

- **WHEN** change готов к архивации, а секция `## Фаза 2. Углубление` содержит невыполненные пункты
- **THEN** агент переносит эти пункты в постоянный реестр расхождений
- **AND** отложенная работа остаётся видимой после архивации change
