## Why

Две находки аудита `coherence-audit-2026-08`, по которым владелец принял решение.

`D-002`: `init-project.sh` копирует каталог модуля `agent-skills` целиком, поэтому в корень каждого нового проекта попадает README модуля. Проект получает файл с заголовком «Portable Agent Skills Module» вместо собственного README, а при применении к существующему проекту его README затирается. Агенту в целевом проекте этот текст не нужен: он адресован тому, кто применяет Workframe, и описывает, как файлы туда попали. Все рабочие правила агент берёт из `AGENTS.md`, `CLAUDE.md`, `docs/` и самих скиллов.

`D-003`: каталоги `source/profiles/` и `examples/` содержат по три одноимённых подкаталога с одной ролью, а `docs/CONCEPTS.md` отсылает к «профилю», не указывая, к какому из двух. Владелец выбрал оставить `examples/`.

## What Changes

- `init-project.sh` копирует payload модуля `agent-skills` перечислением его каталогов, как уже сделано для `design-pencil` и `frontend-quality`. Документация модуля перестаёт попадать в проект.
- Инструкция ручного копирования в README модуля приводится в соответствие: она содержала тот же дефект.
- Каталог `source/profiles/` удаляется; упоминания профилей в правилах, конституции и upgrade guide заменяются ссылкой на `examples/`.

## Capabilities

### Modified Capabilities

- `multi-agent-workflow-adapters`: инициализация ставит в проект payload модуля, но не его собственную документацию.
- `workframe-governance`: `source/` содержит канонические правила и заметки об адаптерах; отдельного каталога профилей больше нет.

## Impact

- `scripts/init-project.sh`, `template/modules/agent-skills/README.md`.
- Удаляется `source/profiles/` с тремя файлами.
- `AGENTS.md`, `docs/CONCEPTS.md`, `docs/UPGRADING.md`.
- `docs/DEBT.md`: `D-002` и `D-003` переходят в `resolved`.
- Поведение уже созданных проектов не меняется: они получают исправление только через собственный upgrade change.
